# Orders grid standard

Canonical Admin Data Grid reference: `/admin/orders` via `AppDataGrid` + `DEFAULT_APP_GRID_CAPABILITIES` + pinned RTL Operations.

Builder Resource Selector (`admin-resource-selector.tsx`) reuses the same profile: column filters, advanced filters, saved views (Host store), pagination, resize, multi-select via selected-items tab, selection across pages, icon Operations with tooltips.
