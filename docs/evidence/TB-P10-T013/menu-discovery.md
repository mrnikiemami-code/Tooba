# Menu discovery

Existing CatalogMegaMenuItem is category-only (BindCategory, unique CategoryId, L1–L3). It is not a general Menu.

Landing sections had no navigation type. Header uses mega-menu when configured, else category taxonomy.

New StoreMenu / StoreMenuItem is the canonical Store-scoped menu. HeaderMenuId on StoreAppearanceSettings mirrors HomePageId. Unset keeps accepted Header fallback.
