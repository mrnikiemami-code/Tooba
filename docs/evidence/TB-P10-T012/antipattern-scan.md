# Anti-pattern scan

CLEAN.

- No generic JSON editor
- No raw SectionType keys in visible Admin copy
- No manual ID entry

- Preview uses the same storefront renderer
- No duplicate Home renderer types
- Reorder is up/down + stable IDs
- No page-local theme
- No polling
- Public Draft remains 404
- Invalid Home falls back
- No rebuild/redeploy
