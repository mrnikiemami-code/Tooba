# Industry template plan — TB-P10-T018

Templates are versioned composition presets from the SAME registry (see `INDUSTRY_TEMPLATE_SEEDS` in registry.ts).

| Key | Industry | Rationale |
|---|---|---|
| fashion | Fashion | Hero+stories+category+product+banner+brand |
| auto-parts | AutoParts | Compact categories + compact product rows + brands |
| building-supplies | BuildingSupplies | Editorial categories + grid + banners |
| tools-hardware | ToolsHardware | Compact tiles + brand/product rows |
| tile-ceramic | TileCeramic | Editorial hero + large cards + mosaic |
| interior-decor | InteriorDecor | Split hero + featured rail + articles |
| home-appliance | HomeAppliance | Category + category-columns + featured brands |
| shoes | Shoes | Story cards + carousel + asymmetric banners |
| plants | Plants | Hero + category rail + reviews |
| beauty | Beauty | Image stories + tabbed products + promo |

Selecting a template creates a normal editable Draft — no template-specific renderer.
