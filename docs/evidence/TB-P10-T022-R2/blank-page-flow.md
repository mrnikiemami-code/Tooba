# Blank page flow

Start blank → language + title/slug → «افزودن بخش» / «افزودن اولین بخش» auto-creates Draft if needed (`openAddSectionWizard` + `saveMeta({ openWizardAfter: true })`) → wizard → first section appears → second section → reorder/preview/publish.

No dead disabled Add Section waiting forever for a hidden page id.
