## Cross-cutting observations

1. **Buy path for seeded catalog is commercially LIVE** (listing → PDP → cart → checkout → sandbox payment → order → fulfillment).
2. **Sell/author path is not closed**: Catalog/Offer/Pricing/Inventory **write foundations exist in modules** but are exercised by **Development bootstrap/tests**, not by seller/admin HTTP + UI required by TB-P06-T021.
3. **No separate Media module** under `src/backend/Modules/`; media is opaque `MediaAssetId` on Catalog + `GET /v1/storefront/media/{assetId}`. Binary upload/authoring HTTP is absent.
4. Architecture lock remains `Catalog Product != Offer`; `Price`/`Stock` never on Product (`docs/architecture/07-catalog-product-offer.md`, `42-catalog-product-variant-foundation.md`).
