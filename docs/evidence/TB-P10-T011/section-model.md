# Section model

`StoreLandingPageSection`: PageSectionId, PageId, SectionType, SortOrder, IsEnabled, schema-validated ConfigurationJson, CreatedAt/UpdatedAt.

No HTML/CSS/JS/SQL fields. Max 40 sections/page. Max take 24. Config ≤ 4000 chars.

Admin UI deferred. API: list/add/update/enable/reorder/delete.
