# TB-P07-T028 — Variant UX redesign

## Goal
Make Product Attributes vs Variants understandable without training. No domain semantics change.

## Guided builder (EDIT)
1. Select variant-enabled attributes (primary category only)
2. Choose option values
3. Human combination preview + count + cap warning (200)
4. Generate / update with create/keep/archive impact wording (no «reconcile»)

## Terminology (normal UI)
- Use: ویژگی، تنوع، ویژگی تنوع، مقادیر قابل انتخاب، پیش‌نمایش تنوع‌ها، ساخت/به‌روزرسانی تنوع‌ها، تنوع پیش‌فرض، بایگانی
- Avoid: محور، Schema، Definition، Axis, Cartesian, Reconcile

## Unchanged
- Primary-only variant eligibility
- Additional categories do not affect variants
- No Product/Variant Price/Stock
- Product cannot create AttributeDefinition
- AppDataGrid / Category Tree / Media / SEO / Publishing / History / Shopeiva
