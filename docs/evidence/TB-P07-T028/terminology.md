# Terminology before / after (T028)

| Before (user-facing) | After |
|---|---|
| محور تنوع / محورهای تنوع | قابل استفاده برای تنوع / ویژگی تنوع |
| مقادیر محورها | مقادیر قابل انتخاب |
| پیش‌نمایش ترکیب‌ها | پیش‌نمایش تنوع‌ها |
| ذخیره تنوع‌ها | ساخت تنوع‌ها / به‌روزرسانی تنوع‌ها |
| schema ویژگی‌ها (workspace gate) | ویژگی‌های وابسته به دسته اصلی |
| جدید / غیرفعال می‌شود (preview) | ساخته می‌شود / بایگانی می‌شود |

Internal code may still use axis/schema identifiers; ordinary Admin UX must not.
