# TB-P08-T012-R1 — Toolbar capabilities

Configured (open-source only):

| Capability | Plugin / item |
|---|---|
| Paragraph / H2–H4 | `Heading` |
| Bold / Italic / Underline / Strike | `Bold`, `Italic`, `Underline`, `Strikethrough` |
| Lists + indent | `List`, `Indent`, `IndentBlock` |
| Blockquote | `BlockQuote` |
| Alignment | `Alignment` |
| Link | `Link` |
| Table | `Table` + properties/caption toolbars |
| Undo / Redo | `Undo` |
| Find / Replace | `FindAndReplace` |
| Image from DAM | custom `DamImageInsert` (`damImage`) |
| Image alt / caption / style / resize | `ImageTextAlternative`, `ImageCaption`, `ImageStyle`, `ImageResize` |

Not enabled: SourceEditing, CKBox, CloudServices, EasyImage, Base64/Simple upload adapters, MediaEmbed.
