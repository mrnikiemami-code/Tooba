# User inspection guide — TB-P10-T017

Host `:5088`، فروشگاه و پنل `:3000`.

## ظاهر فروشگاه
`http://127.0.0.1:3000/admin/settings` → زبانه **ظاهر فروشگاه**.

۱. پالت را از هفت گزینه انتخاب کنید: آبی توبا، سبز جنگلی، شرابی تیره، سرمه‌ای سنگی، کهربایی، سبزآبی مرداب، بنفش سلطنتی.
۲. **پس‌زمینه فروشگاه** را روی **رنگی ملایم** بگذارید و ذخیره کنید.
۳. پیش‌نمایش چهار نوار را ببینید:
   - زمینه صفحه
   - بخش اصلی
   - بخش جایگزین
   - بخش برجسته

## حالت روشن / تاریک
در همان صفحه **تم** را عوض کنید (فقط روشن / فقط تاریک / سیستم / انتخاب کاربر). در فروشگاه، اگر تم انتخاب کاربر باشد، سوییچ هدر را هم امتحان کنید.

## پوسته‌های کارت
چهار پوسته کارت را جدا از رنگ صفحه ببینید؛ کارت باید از زمینه و نوارها جدا بماند.

## مسیرهای فروشگاه برای مقایسه
با **رنگی ملایم** این صفحات را باز کنید:

- خانه: `http://127.0.0.1:3000/fa`
- فهرست کالا: `http://127.0.0.1:3000/fa/products`
- صفحه کالا (از همان فهرست)
- محتوا / مقاله: `http://127.0.0.1:3000/fa/blogs`
- سبد: `http://127.0.0.1:3000/fa/cart`
- ارسال / تسویه: `http://127.0.0.1:3000/fa/shipping`
- حساب / علاقه‌مندی: `http://127.0.0.1:3000/fa/customer-panel` و `.../wishlist`
- لندینگ منتشرشده: `http://127.0.0.1:3000/fa/landing-campaign`

## لندینگ، خانه و منو
- صفحات فرود: `http://127.0.0.1:3000/admin/landing-pages`
- منوها: `http://127.0.0.1:3000/admin/menus`
- برای دیدن لندینگ به‌جای خانه: روی ردیف منتشرشده **صفحه اصلی** را بزنید، سپس `/fa` را ببینید.
- برای برگشت خانهٔ اصلی: **لغو خانه**.

## بازگردانی پیش‌فرض
ظاهر فروشگاه را برگردانید به: **آبی توبا** + **فقط روشن** + **کلاسیک** + **خنثی**، ذخیره کنید، و خانهٔ متعارف را برگردانید.
