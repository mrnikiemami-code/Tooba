# error-ux.md

`admin-error-map.ts` adds friendly fa/en messages for:

- `content.article.locale_locked`
- `content.article.create_failed`
- `content.author.not_found`
- `content.author.inactive`
- `content.author.required_for_publish`
- `localization.language.inactive`

Article workspace save/create surfaces mapped messages (no raw HTTP titles). Locale locked copy in UI matches the Persian locale_locked message.
