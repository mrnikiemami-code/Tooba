# Contextual help (TB-P08-T015)

## Pattern

- Reusable `ContentHelpAffordance` (`?` button → popover)
- Shared keys/copy in `content-help-content.ts`
- Link to central `/admin/content/help#key`

## Placement

Help near Language, Author, Category, Tags, Featured/Gallery/Inline/Share images, SEO, Home feature, Publication concepts, History, Comments.
