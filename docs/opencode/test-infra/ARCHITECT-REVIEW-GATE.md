# Architect independent acceptance gate (v1.5.0)
This extends, does not replace, ARCHITECT-QUALITY-GATE.md or acceptance-gate.cjs. The owner requires architect-owned repairs and no dependent next task without independent review. Run from the actual Git checkout:
```sh
node docs/opencode/test-infra/architect-review-gate.cjs --self-test
node docs/opencode/test-infra/architect-review-gate.cjs TASK_ID BASE_SHA CANDIDATE_SHA EVIDENCE_COMMIT ARCHITECT-REVIEW.json MATRIX [MATRIX...]
```
Use full immutable SHAs. BASE is issued task base, CANDIDATE is tested product SHA, EVIDENCE_COMMIT contains actual logs and is a descendant without any product change. Evidence task-folder additions are excluded from product diff; all other changed paths are checked, including deletions. Use the exact task's issued matrix/matrices; for a phase use its pre-issued immutable scoped test matrix, not all future phase tests or a new handpicked subset. Architect verifies matrix paths/hashes against issued TASK before running; never use edited/worker-selected matrix. Preserve existing acceptance verifier and raw outputs. Store review and checker output under task; evidence commits must not change product. Re-run for any changed product SHA. Worker validates dependency receipt against predecessor task/base/candidate and actual checker output before starting dependent next task, not merely a PASS word.

## Receipt shape
JSON keys: schemaVersion:1, reviewerRole:"ARCHITECT", taskId, base, candidate, evidenceCommit, decision:"ACCEPT". reviewedFiles: every changed path (beforeBlob, afterBlob exact Git object IDs or null if absent, observation concrete review). checks: exact AQ-01..AQ-08, status PASS or reasoned NOT_APPLICABLE for genuinely irrelevant gates, reason, sourceRefs, evidenceRefs. Each sourceRef: revision "base" or "candidate", path, blob (git rev-parse REF:path), startLine, endLine, finding. Each evidenceRef: path, blob at EVIDENCE_COMMIT, observation with command/observed result. Validation: build, architectureGuards, openSpec, acceptanceVerifier, cleanup each status PASS plus evidence reference. tests: exactly mandatory matrix testIds, status PASS, raw evidence reference. findings: every material defect/gap with id, disposition FIXED or UNRELATED_BASELINE, rootCause, prevention, owner, sourceRefs/evidenceRefs; FIXED requires owner ARCHITECT and repairCommit ancestor of candidate; baseline requires baselineReason and actual baseline proof. Empty findings only if independent review found none. Any unresolved finding or NOT_RUN blocks ACCEPT; document blocked review separately. Use real source refs for N/A to demonstrate absence of relevant changes.
For AQ-01 specifically trace DB language registry, active/default/fallback, route/provider, API locale, all touched user-visible labels/errors, RTL/LTR and actual shared consumers; backend-only tasks must still verify localized error resources and wire keys. AQ-02..08 use canonical quality gate. Review changed and surrounding code, not just strings or tests; compare architecture failure identities against baseline. Gate does not authenticate reviewer identity, certify semantic correctness, enforce remote branch protection, or prove that logs are truthful. It mechanically rejects missing fields, stale/tampered refs, missing paths, mandatory failures/waivers, missing tests, unclosed findings and post-test product changes. Architect remains personally accountable and must perform the actual source audit. No bypass by changing matrices, guard baselines or receipt metadata.
