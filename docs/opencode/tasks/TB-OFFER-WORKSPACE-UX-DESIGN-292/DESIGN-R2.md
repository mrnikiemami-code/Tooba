# DESIGN (R2) — حل ایرادات UX + رفتار وابسته (TB-292-R2)

Frontend Design tool (Impeccable) اجرا و شاهد رندرشده در `evidence/audit-r2-result.json` ثبت شد. چیدمان به‌عهدهٔ طراح.

## حل ۱۱ ایراد UX
1. طول/اسکرول زیاد → فرم در گرید دوستونی فشرده (بخش‌های ضروری کنار هم)، «تنظیمات پیشرفته» به‌صورت accordion جمع‌شده.
2. فضای خالی طرفین → عرض محتوا 1200px با پدینگ 24px؛ بدون ستون کنارِ خالی.
3. فشردگی محتوا → فاصلهٔ 14px بین کارت‌ها، پدینگ 14–16px، اندازهٔ متن پایه 15px.
4. نوار عملیات روی فیلدها → نوار پایین حذف شد؛ فقط یک دکمهٔ ذخیره در هدر چسبان فرم (بدون هم‌پوشانی: overlap=0).
5. تکرار دکمهٔ ذخیره → تنها یک «ذخیره آفر» (هدر)؛ دکمهٔ تکراری پایین حذف شد.
6. متن کوچک/کنتراست ضعیف → کمینهٔ فونت 13px، کنتراست متن 16.4:1 و muted 6.99:1 (WCAG AA/AAA).
7. خوانایی جدول‌های داخلی → پدینگ 9–10px، zebra، هدر پررنگ، فونت 13px.
8. اولویت عملیات → «ذخیره آفر» primary (توپر)، انصراف ghost؛ دیگر دکمه‌ها ثانویه.
9. دسترسی به عملیات پرتکرار → اکشن‌های ردیف در جدول + هدر چسبان.
10. ضروری/پیشرفته هم‌زمان → پیشرفته (چندارزی کامل، تخفیف، تاریخچه) پنهان در «تنظیمات پیشرفته».
11. اصطلاح فنی → نام دامنه‌ها حذف شد؛ زبان کاربری.

## الزامات رفتاری (همه در audit=true)
- فروشنده/محصول انتخاب‌نشده → بخش‌های وابسته قفل (depsLockedWhenEmpty=true، depsEnabledAfterSelect=true).
- مسئولیت ارسال تعیین‌نشده → سرویس غیرفعال (serviceDisabledWhenUnset=true)؛ بعد از تعیین → فعال.
- غیرقابل‌مرجوع → فیلد مهلت پنهان (retWindowHiddenWhenNone=true).
- پیش‌نویس → غیرقابل خرید (createNotBuyable/draftNotBuyable=true)؛ فعال → قابل خرید.
- واحد/گام/اعشار فقط‌خواندنی (unitReadonly=true).
- هویت انبار ثبت‌شده قفل (warehouseLocked=true).
- خلاصهٔ چندارزی با ارز/بازار (در «تنظیمات پیشرفته»).
- فرم ایجاد جدید → بدون تاریخچهٔ ساختگی (historyHiddenOnCreate=true).
- حالت خطای بخش (errorShown=true) + محافظ تغییرات ذخیره‌نشده.
