Reproduced-cause mechanism (FluentValidation default CascadeMode.Continue):
  a failing NotNull() rule does NOT stop the following rule from being evaluated, so the nested
  property expression x => x.Scope.CountryId is dereferenced with x.Scope == null and throws
  NullReferenceException, which is not a SemanticError and therefore escapes the canonical
  validation.failed 4xx path as platform.unexpected / 500.
