## REPRODUCED DEFECT (recorded, not fixed — outside this task's necessity test)

`POST /v1/admin/shipping-services/post/rates` with a body that omits `scope` returns
`500 platform.unexpected / NullReferenceException` instead of a `400` validation failure. Host log:

```text
NullReferenceException occurred when executing rule for x => x.Scope.CountryId.
If this property can be null you should add a null check using a When condition
  at lambda_method2393(Closure, ShippingRatePolicyWriteRequest)
  at FluentValidation.Internal.PropertyRule`2...PropertyRule.cs:line 43/149/152
```

Cause: a validator rule dereferences `ShippingRatePolicyWriteRequest.Scope` although the record property is
non-nullable but not required by the JSON binder, so an omitted member deserialises to `null`.
Reproduction is deterministic (2/2 attempts). **Not fixed here**: the mission's acceptance criteria were met
without it, it is not architecture- or security-boundary related, and the task authorises a code change only
for a directly reproduced *blocking* defect. Recommended follow-up: a `NotNull`/`When` guard in the
`ShippingRatePolicyWriteRequest` validator so a missing scope fails as `400`.
