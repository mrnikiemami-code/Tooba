DELIVERABLE (one additive owner-correct read model + Admin representation)
The Shipping module (owner of rate/coverage rows) now exposes ONE read-only seam for the financial
status of ONE canonical method:
  GET /v1/admin/shipping-services/{serviceCode}/financial-status?optionCode=<option|omitted>
Authorization is the EXISTING admin permission fulfillment.view via IShippingAdminAuthorizer; 401/403
fail closed, there is no anonymous path, no write verb and no Manage permission. optionCode omitted or
empty means the service-level (optionless) method identity. The Admin General tab renders the verified
state, reason, and money ONLY when authoritative, while preserving the four top-level tabs, dynamic
languages, compact RTL design and the canonical method binding.

EVALUATION (deterministic, pure, no IO, no current time, no invented policy)
ShippingMethodFinancialStatusEvaluator over the real ShippingRatePolicy/ShippingCoverageGrant rows:
1) Owned rows are ONLY those whose serviceCode AND optionCode equal the authoritative identity pair.
2) No owned row + method has an option + service-level (optionCode null) rows exist => LegacySharedUnresolved
   (shipping.financial.legacy_service_level_shared): rules empty, NO amount, NO currency, NO free. The
   legacy provider-level tariff is counted for audit only and never projected as this method's price.
3) No owned row and no service-level row => NeedsConfiguration (shipping.financial.no_owned_rules).
4) Owned rows with more than one currency OR two owned rows with identical scope+condition => Conflicting
   (mixed_currency / ambiguous_owned_scope); no single amount is asserted, first-row-wins is refused.
5) Otherwise FinanciallyConfigured / Mode=FixedAmount (shipping.financial.owned_rules_present).
   A stored zero is a data fact (hasZeroChargeRule) only: the schema has no approved FREE mode.
6) Optionless methods OWN their service-level rows and are never reported as legacy shared.
Sibling options are surfaced as a COUNT (activeSiblingOptionRuleCount) for visibility; their rates can
never become this method's money. Coverage is reported as a count (activeCoverageGrantCount) and is NOT
a universal quote-ready claim.

MONETARY MODES TRULY SUPPORTED BY THE CURRENT OWNER (concise table; evidence file monetary-modes-table-155.md)
