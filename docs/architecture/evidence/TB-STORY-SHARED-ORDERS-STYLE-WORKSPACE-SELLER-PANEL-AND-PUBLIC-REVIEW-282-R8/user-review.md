# بررسی کاربر — استوری (TB-282-R8)

آدرس‌ها (Host `5088` / Next `3000`):

- `/fa/admin/stories` فهرست؛ `/fa/admin/stories/new` فرم کامل؛ `/fa/admin/stories/{id}` ویرایش
- `/fa/vendor-panel/stories` و `/new` و `/{id}` داخل همان پنل فروشنده
- `/fa` ویترین

چه چیزی عوض شده:

1. اگر ایجاد پیش‌نویس جواب نامشخص بدهد، کارت «اقدام ناتمام» می‌آید؛ ذخیرهٔ دوباره پیش‌نویس تازه نمی‌سازد.
2. با «ادامه» همان درخواست قبلی تکرار می‌شود و در صورت موفقیت، همان پیش‌نویس باز می‌شود (نه ساخت دوباره).
3. با Host بدون bootstrap توسعه، مسیر هویت مدیر موجود (`/v1/admin/dev-context`) دیگر خالی نیست.

نوشتن زنده در این تسک انجام نشده. Worker PASS ≠ پذیرش معمار ≠ پذیرش صاحب محصول.

محدودیت: با skip-bootstrap، مجوزهای InMemory ممکن است برای فهرست زندهٔ استوری 403 بدهند؛ فرم و بازیابی در تست مونت ثابت شده‌اند.
