EXPLICIT BEHAVIOUR DISCLOSURE (deliberate, not silent)
Because the locale argument was omitted, at runtime `locale === "fa"` was false, so the cell fell through to d.format("YYYY-MM-DD") and displayed a GREGORIAN date under a Persian "تاریخ انتشار" header while its own filter panel showed Jalali. Supplying "fa" therefore intentionally changes the rendered cell text from YYYY-MM-DD to Jalali YYYY/MM/DD, aligning it with the formatter contract, the sibling column, the grid default and the same column's date filter. This is the repair, stated openly rather than presented as a no-op.
