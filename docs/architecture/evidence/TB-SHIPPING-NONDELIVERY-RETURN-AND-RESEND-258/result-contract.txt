MEASURED DEFECT (before this task):
    A dispatched parcel offered only «ثبت تحویل» and the pre-dispatch «لغو». A courier return could not be recorded,
    there was no durable origin receipt, and no lawful resend parcel could exist. Marking Delivered would have been a
    lie, and using the cancel path after dispatch would have erased the shipped truth.

TRANSITIONS (parcel level, additive):
    Dispatched/InTransit -> «ثبت عدم تحویل» -> NonDelivered -> «برگشت به مبدأ» -> Returning
      -> «تأیید دریافت در مبدأ» -> Returned (+ durable ShipmentReturnReceipt, per-line Usable/Damaged)
      -> «ارسال مجدد» -> NEW parcel (ResendOfShipmentId = original, Created) -> existing track/dispatch/deliver.
    A later genuine delivery may resolve a non-delivery; Delivered never becomes NonDelivered; Created cannot skip
    dispatch; return needs a recorded non-delivery; receipt needs Returning; resend needs a physical receipt.
    Customer RMA after a successful delivery stays a separate existing path; no universal cancel-after-dispatch.

QUANTITY / INVENTORY CONSERVATION:
    ReturnedUsableQuantity = Σ usable receipt lines (damaged/missing contribute ZERO).
    ResendCommittedQuantity = Σ non-cancelled resend parcel lines (a cancelled pre-dispatch resend releases once).
    ResendableQuantity = max(0, usableReturned − resendCommitted).
    OpenAllocatedQuantity ignores Created resend parcels, so a resend never shrinks the fresh 257 packed remainder.
    DeliveredQuantity counts Delivered parcels only; a delivered resend counts once; one other in-transit parcel
    keeps the whole unit not-delivered. No lifetime-shipped decrement, no ordered/packed inflation, no second
    reservation consume, no settlement/financial movement, no money change.
