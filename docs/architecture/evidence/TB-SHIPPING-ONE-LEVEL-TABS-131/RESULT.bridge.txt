SUBSTANTIVE RESULT
Customer-facing grouped Shipping/Checkout presentation built strictly on the existing Order-owned
grouped projections (no new backend contract, no parallel source of financial truth).
/shipping: when the real cart projection contains more than one authoritative SellerPartyId group, the
page renders one scoped card per seller group containing the REAL cart lines (media, title, quantity,
real CartLineId identity) and an explicit per-group method choice whose price, localized label and
lead time all come from the server-evaluated projection.methods[]. "/continue to payment" then submits
the incremental shippingGroups[] (shippingMethodCode + real cartLineIds + authoritative serviceCode)
to the existing PUT /v1/storefront/shipping/selection. Single-seller carts keep the legacy scalar
shippingMethodCode path and the previous DOM (guarded by isGroupedCart), so the legacy cart-wide
selection remains fully supported and visually unchanged.
/checkout (payment): the Order-owned shippingGroups list from the checkout projection is now mapped and
rendered - per-group localized method label, scheduled delivery date and authoritative per-group fee,
plus a reconciled shipping total row; the legacy single-label rendering is retained when no groups exist.
Return/refresh: saved draft.shippingGroups are restored into per-group selection state; no automatic
method conversion and no commit/reservation/order creation from navigation.

API PROVENANCE (all pre-existing contracts, consumed only)
- POST /v1/storefront/shipping/projection -> draft.shippingGroups[] (StorefrontShippingGroupView:
  shippingGroupId, sellerPartyId, methodCode, serviceCode, optionCode, methodLabel, shippingAmount,
  currency, minimumDeliveryDate, selectedDeliveryDate, selectedDeliveryTimeWindow, leadDays, lineCount).
- PUT /v1/storefront/shipping/selection -> shippingGroups[] (StorefrontShippingGroupSelection:
  shippingMethodCode, cartLineIds, serviceCode, optionCode) sent only for multi-seller carts.
- Checkout projection -> shippingGroups[] (Order-owned StorefrontShippingGroupView) now mapped into
  StorefrontCheckoutPage.shippingGroups.
- GET /v1/storefront/cart -> StorefrontCartLine.lineId/sellerPartyId/sellerDisplayName/title/
  mediaAssetId/quantity used verbatim as group membership identity.

client-side; the client only sums already-authoritative per-group prices for the summary row.
