MISSION A — ROOT CAUSE (source, cited)

`methods.Any(m => m.MethodCode == draft.ShippingMethodCode)`. CartShippingDraft.AddShippingGroups sets
`ShippingMethodCode = multiGroup ? string.Empty : first.MethodCode` — so a multi-seller draft ALWAYS has an empty
shorthand and the guard was always false: draft discarded + "انتخاب ارسال دیگر معتبر نیست…" + minimumDeliveryDate
null + deliveryDates empty on every cold reload. Single-group legacy drafts were unaffected (non-empty shorthand).
Persisted row observed in the scratch DB confirms the empty shorthand (see below).
