# چک‌لیست بررسی صاحب محصول — استوری (TB-282)

آدرس‌ها (سرویس محلی):

- ادمین: http://127.0.0.1:3000/fa/admin/stories
- پنل فروشندهٔ موجود: http://127.0.0.1:3000/fa/vendor-panel/stories
- ویترین عمومی (خانه): http://127.0.0.1:3000/fa

مراحل (هر مرحلهٔ نوشتن با ★ دادهٔ واقعی می‌سازد یا منتشر می‌کند):

1. با حساب ادمین وارد شوید و فهرست استوری را ببینید (مرتب مثل سفارش‌ها).
2. با فروشگاه وارد پنل فروشنده شوید و منوی «استوری‌ها» را باز کنید (همان قالب؛ پنل تازه نسازید).
3. ★ «استوری جدید» → عنوان → ذخیره پیش‌نویس.
4. ★ فایل عکس یا ویدیو انتخاب و «افزودن اسلاید».
5. ★ «ارسال برای تأیید».
6. در ادمین همان استوری را باز کنید، محتوا را ببینید، ★ «تأیید و انتشار» یا ★ «رد با دلیل».
7. در خانه استوری منتشرشده را پخش کنید؛ نام فروشگاه و لینک فروشگاه (اگر دارد) را چک کنید. لایک/کامنت جعلی نباید باشد.
8. لینک اشتراک (`?story=…`) فقط همان استوری واجد شرایط را باز کند.

کارگر این نوشتن‌های زنده را انجام نداده است؛ تست فنی ≠ پذیرش شما.
