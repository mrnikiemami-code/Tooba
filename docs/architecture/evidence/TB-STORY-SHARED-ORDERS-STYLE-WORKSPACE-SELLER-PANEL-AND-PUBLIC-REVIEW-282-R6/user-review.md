# بررسی کاربر — استوری (TB-282-R6)

آدرس‌ها (Host `5088` / Next `3000`):

- `/fa/admin/stories` فهرست؛ `/fa/admin/stories/new` فرم کامل؛ `/fa/admin/stories/{id}` ویرایش
- `/fa/vendor-panel/stories` و `/new` و `/{id}` داخل همان پنل فروشنده
- `/fa` ویترین

چه چیزی عوض شده:

1. «استوری جدید» دیگر فقط عنوان نیست؛ همان فرم کامل با محل نمایش، اسلاید، پیش‌نمایش و ذخیره است (ادمین و فروشنده).
2. فیلتر بازبینی فقط در فهرست ادمین است؛ داخل ساخت/جزئیات دیده نمی‌شود.
3. محل نمایش: ویترین اصلی یا نام واقعی فروشگاه؛ اگر نام نباشد «ناموجود» است نه کد.
4. مقصد اسلاید با زبان فروشگاهی است (بدون لینک / محصول / فروشگاه / پیوند)، نه واژهٔ فنی.

نوشتن زنده در این تسک انجام نشده. Worker PASS ≠ پذیرش معمار ≠ پذیرش صاحب محصول.

محدودیت: دکمهٔ مقصد اسلاید تازه همان گزینه‌های قبلی است (بدون لینک / محصول / پیوند). مقصد ذخیره‌شدهٔ internal به‌صورت «فروشگاه» دیده می‌شود؛ نوع تازهٔ جداگانه در فرم اضافه نشده چون قرارداد ذخیره‌شده عوض نشده است.
