§12 — Limitations of this evidence
- Requests were fulfilled by an in-page fixture, not the real Fulfillment database. The wire contract,
  path, method, DTO shape and the screen's own code are real; the persistence of that contract in
  Postgres is covered by the existing backend tests, not by this run.
- `window.confirm` was replaced by an equivalent probe, so the native dialog's own rendering was not
  exercised; the confirm boundary (message text + both answers) was.
- No Playwright/jsdom component harness exists in this repo (node --experimental-strip-types cannot
  import .tsx JSX), so a durable in-repo React render test was not added; the durable in-repo
  regression is the fetch-level roundtrip test shipping-services-roundtrip.test.ts.
