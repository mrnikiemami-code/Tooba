Conclusion: reaching the storefront shipping projection on the shared Development data set requires
either a cart owned by the current session (none exists) or a guest secret for an existing cart
(not recoverable). Producing either would require DML (cart creation / line insert) or credential
guessing, both explicitly forbidden by this task => PARTIAL / BLOCKED_REAL_STOREFRONT_PROOF.
