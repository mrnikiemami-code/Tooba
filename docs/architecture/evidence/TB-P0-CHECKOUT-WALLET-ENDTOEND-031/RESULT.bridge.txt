   exposed. Wallet can never be initiated for a guest because selection/validation require

   011 read path; `CartPaymentQuoteBridge` maps every Order fault to a typed status, so no Order stable
   code leaks and no `PaymentErrorCodes` entry, descriptor, resource or count changed.

   CartNotActive / Unavailable are returned as `cartQuoteStatus` with zeros and eligibility false.
   Unknown-owner codes fail closed instead of guessing.
6. No fabricated numbers anywhere: `mixedTenderAvailable` stays false (partial wallet tender deferred),
   `manualCardToCardEnabled` is read from the canonical catalog port.
