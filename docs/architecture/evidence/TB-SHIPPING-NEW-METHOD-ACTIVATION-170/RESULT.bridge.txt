SUMMARY
The concrete TB-169 gap - a newly created canonical flat method could be named but not activated -
is closed inside the correct module owners, with no fabricated provider capability, rate, coverage,
legacy option row, delivery promise or financial readiness.

Fulfillment (method identity/activation owner): ShippingOneLevelCatalogActivation no longer requires
a legacy shipping_service_options row for a method whose parent service exists and is active. Such a
method is activated on the shipping_methods row only and reports ActivatedCanonicalOnly; no legacy
option row is created to satisfy the guard. Missing or inactive parent service still fails closed
(LegacyBindingMissing / LegacyParentInactive) because provider registration is a genuine prerequisite,
and legacy-bound methods keep the exact previous two-row transactional alignment. The activation DTO
gained an additive canonicalOnly flag so Admin can see that activation is an admin projection, not
customer readiness.

Contracts/infrastructure: new read-only IShippingOneLevelCanonicalMethodReader (+
ShippingOneLevelCanonicalMethodRead) declares active canonical methods that have an active parent
service and no legacy option row, and confirms whether a real canonical method binds a given
service+option. It is gate-aware and fail-closed (gate off, unmigrated table, invented code => empty
or false), reads only the Fulfillment owner DbContext, and exposes no EF model or price.

Shipping (rate/coverage/quote owner): FulfillmentShippingMethodOptionValidator accepts that real
canonical identity as an owned rate key when the legacy option list has no such option; invented
option codes remain refused with shipping.service_option.unknown and the gate-off path grants nothing.

Order (customer eligibility consumer): StorefrontShippingService adds canonical-only methods as
owned-rate candidates only when Tooba:ShippingOwnedRateAuthority is ON (zero seam calls when off) and
exposes such a method to the customer only when the same round produced a real Shipping quote; price
and lead days come from that quote, no fallback/free/zero price is ever emitted, and unquoted
canonical drafts are not announced in the legacy "unavailable" list.
