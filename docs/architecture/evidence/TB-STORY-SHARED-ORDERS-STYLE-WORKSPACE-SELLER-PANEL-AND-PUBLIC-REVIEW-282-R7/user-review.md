# بررسی کاربر — استوری (TB-282-R7)

آدرس‌ها: `/fa/admin/stories` ، `/fa/vendor-panel/stories` ، `/fa`

چه چیزی درست شد:

1. افزودن اسلاید دیگر فرم را خراب نمی‌کند؛ پیش‌نویس یک‌بار ساخته می‌شود و پس از رفتن به صفحهٔ جزئیات، پنجرهٔ اسلاید باز می‌شود.
2. پیش‌نمایش اسلایدهای ذخیره‌شده واقعی است (عکس/ویدیو و مقصد).
3. اگر فرم را عوض کرده باشید و برگردید، سؤال «ادامهٔ ویرایش / خروج بدون ذخیره» می‌آید.
4. مقصدهای قدیمی غیرفروشگاهی دیگر «فروشگاه» اشتباه نشان داده نمی‌شوند؛ مبدأ ساخت «مدیر / فروشنده» است نه محل نمایش.
5. Host با حالت امن بدون bootstrap بالا آمده؛ ورود ادمین توسعه‌ای از مسیر dev-context در این حالت در دسترس نیست — بررسی زندهٔ لاگین ادمین در این تسک ادعا نشده.

نوشتن زندهٔ استوری انجام نشده. Worker PASS ≠ پذیرش معمار ≠ پذیرش صاحب محصول.
