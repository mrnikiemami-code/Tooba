== RESIDUAL RACE — explicitly not an invariant proof ==

The flag design is read-payability -> insert payment/attempt -> call provider. The cycle can expire
(observed alpha policy initial_reservation_hold_minutes = 1) between the read and the insert. This
reduces but does NOT eliminate the window. It is NOT atomic and must never be described as race-free;
no single-transaction/lock/CAS proof exists today.

Atomic coordination designs (required before the final-click endpoint can follow):
 A (preferred) CAS in Order, verified inside a shared transaction: make the existing
   IReservationCycleDirectory.CorrelatePaymentAttemptAsync conditional
   (WHERE status = Active AND expires_at > now -> returns false instead of no-op) and have Payment call it
   inside an ambient TransactionScope around its own SaveChangesAsync. Single physical database, same
   mechanism the checkout commit already uses (CheckoutProcessManager.cs:95-99). Needs an Order Contracts
   change and an explicit Payment transaction boundary — separately authorized work.
 B Order-owned composite call: commit + payability + correlation inside the existing commit transaction,
   returning a token Payment must validate at initiation. Same Order Contracts change; still needs the typed error.

Until one is authorized, the 012R IPaymentInitiationPort has no production caller and no endpoint exists,
so the missing gate is not reachable.
