The media tab passed the raw call to <img src>, and <img>.src accepts string | Blob | undefined, so string | null is not assignable -> TS2322 at content-category-admin-screen.tsx:507.

DECISION GATE — WHAT NULL MEANS (established from the real code)
1. null == absence of a usable media asset id. The helper is a pure string template with no other failure mode: it cannot fail for a non-blank id and cannot succeed for a blank one.
2. A present mediaAssetId CAN yield null only when it is blank/whitespace-only ("" or "   "), because of the `.trim()` + `if (!id) return null` guard — no genuinely-present id is non-previewable. So "has id" and "has URL" are the same predicate for all real data; the only divergence is the blank-string edge.
3. Existing representation of absent media on this tab: <p className="text-sm text-muted">تصویری اختصاص داده نشده است.</p> (line 509) — preserved verbatim.
