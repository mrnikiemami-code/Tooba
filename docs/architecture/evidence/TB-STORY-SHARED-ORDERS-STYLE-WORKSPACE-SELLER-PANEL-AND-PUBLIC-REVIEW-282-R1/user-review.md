# بررسی کاربر — استوری (TB-282-R1)

آدرس‌ها (پس از سرو Host/FE):

- `/fa/admin/stories` و `/fa/admin/stories/new` و `/fa/admin/stories/{id}`
- `/fa/vendor-panel/stories` و `/new` و `/{id}` (همان VendorShell)
- `/fa` ریل عمومی

چک‌لیست کوتاه:

1. فروشنده: استوری جدید → اسلاید عکس/ویدیو → زیرنویس → ارسال برای تأیید
2. ادمین: انتخاب فروشگاه با **نام** (نه شناسه) → پیش‌نمایش قبل از تأیید انتشار
3. اقدام ناتمام پس از قطع شبکه روی همان کلید دوباره ارسال می‌شود
4. ویترین: دکمه محصول به مسیر `/products/{slug}` می‌رود (نه Guid خام)

نوشتن زندهٔ استوری/مدیا در این تسک انجام نشده؛ اولین عمل زنده با کاربر است.
