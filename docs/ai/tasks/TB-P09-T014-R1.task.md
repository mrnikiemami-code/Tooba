2. Canonical Semantics
LineCount / TotalItemCount

Number of distinct order/invoice lines.
Type: integer.

Example:
3 lines with qty 1.25, 2.00, 1
=> LineCount = 3

TotalQuantity

Mechanical sum of product quantities.
Type: decimal.

Do not label TotalQuantity as تعداد اقلام.

Because units may differ, do not present TotalQuantity as one physically meaningful shared-unit total unless context explicitly supports it.
