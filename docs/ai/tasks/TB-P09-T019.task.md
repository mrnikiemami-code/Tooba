6. Split Delivery / Quantity-Aware Returns

Return eligibility must be quantity-aware.

Example:
OrderLine quantity = 1.25 kg

Deliveries:

0.50 delivered on day A

0.75 delivered on day B

The system must not treat the full 1.25 as delivered on day A.

Returnable quantity must account for:

delivered quantity

already requested

approved/in-progress

already returned

expired/non-returnable portions where current model tracks clocks per delivery allocation

No integer truncation.

If current domain cannot represent per-delivery deadline allocation exactly, document the existing representation and make the minimal safe repair needed to satisfy already-locked split-delivery semantics. Do not fake a single earlier deadline.
