Locked Product Rules

Customer Order is summary/context.

Fulfillment operations are seller-scoped.

Operational hierarchy:

Order

Seller Order / seller group

Shipment

OrderLine + Quantity

One Order may contain multiple sellers.

One seller group may have multiple shipments.

One shipment belongs to one seller and one shipping method.

Same Order may use different shipping methods across shipments.

Operations support BOTH:

whole-group fast path

selected-line / selected-quantity path

Whole-group and selected modes use SAME backend/domain command logic.

Cross-seller shipment operations are forbidden.

Reverse transitions are rule-based, never globally reversible.

Return = مرجوعی

Refund = بازگشت وجه

Return eligibility/policy is line-level and snapshotted at purchase.

History stays on current Order Detail page.

Grid row kebab is whole-order scope only.

No heavy redesign.
