D — Stuck Work / Lease Safety

For durable work:

claimed work must have lease/lock semantics

crashed worker must not permanently orphan work

retry eligibility must be deterministic

duplicate claim must be safe

Use PostgreSQL-safe locking where appropriate:

SKIP LOCKED

advisory lock

row state + lease expiry

Do not use in-memory locks for durable work.
