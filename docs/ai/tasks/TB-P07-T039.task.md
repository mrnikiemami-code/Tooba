ARCHITECT DECISION

Current behavior has two defects:

UI uses one generic message (تنوع برای این نوع مقدار مناسب نیست) even when the real cause is IsVariantAxisAllowed=false.

IsVariantAxisAllowed is treated as permanently immutable, which can force duplicate AttributeDefinitions.

Locked semantic separation:

AttributeDefinition.IsVariantAxisAllowed = this attribute MAY be used as a variant axis.

Category binding IsVariant = this Category ACTUALLY uses the attribute as a variant axis.

Product Variants are driven by the effective Primary Category variant schema.
