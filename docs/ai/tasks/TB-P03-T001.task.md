Slug / SEO Boundary

Catalog may own canonical entity slug data/reference if already decided, but SEO route/indexation policy remains SEO capability.

Do not put:

Media Boundary

Catalog Product/Variant may reference media assets by opaque MediaId/reference.

Do not store binary/image transformation logic in Catalog.

No direct Media table FK across modules.
