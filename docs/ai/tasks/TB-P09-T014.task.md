8. Line-Level Financial Finalization

Inspect existing Line financial calculations.

Locked rule:
Each Line financial calculation result is finalized/rounded according to the canonical GlobalRoundingMode + effective monetary precision at the point the calculation is produced.

Example:
Gross = 998
DiscountRate = 20%
RawDiscount = 199.6
Floor + money precision 0:
DiscountAmount = 199
LineNet = 799

The finalized Line values then feed Header sums.

Do NOT perform an extra rounding pass on Header merely because it sums finalized Line values.

12. Header Derivation / Persistence

When Invoice is issued/finalized:

derive Header aggregates from finalized Line values

persist/snapshot Header aggregates

list/detail/report query reads Header directly for primary totals

Invariant examples:

sum(Line.GrossAmount) = Header.GrossAmount

sum(Line.DiscountAmount) plus valid invoice-level discount adjustments = Header.TotalDiscountAmount

sum(Line.TaxAmount) = Header.TotalTaxAmount unless explicit invoice-level tax adjustment exists

sum(Line.DutyAmount) = Header.TotalDutyAmount unless explicit invoice-level duty adjustment exists

TotalTaxAndDutyAmount = TotalTaxAmount + TotalDutyAmount

PayableAmount matches finalized financial composition

Do not recompute historical values from current Product/Offer settings.
