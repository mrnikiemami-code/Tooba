## 3. Confirmed Commercial Model

Architecture must preserve exactly these confirmed product facts.

### Marketplace Edition

```text
one dedicated Marketplace publish/deployment
one Marketplace database in the currently stated model
multi-seller marketplace behavior
```

### Single-Store Commercial Edition

```text
one shared publish/deployment
many commercial customer stores
many incoming domains
incoming Host -> resolve store/tenant -> resolve correct database
one database per customer/store
theme per store
not multi-vendor
```

Important:

There are two publish/deployment products:

```text
Tooba Marketplace deployment
Tooba Single-Store shared deployment
```

Do NOT misinterpret the requirement as one runtime deployment serving Marketplace and Single-Store simultaneously.

Shared source/product architecture is desired; deployment topology differs by edition.
