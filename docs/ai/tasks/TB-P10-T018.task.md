Architect Decision

Appearance/Theme through TB-P10-T017-R5 is visually accepted.

New scope:

many curated Variants

only essential, risk-driven tests

Locked Product Rules
Shared Engine

Home and Landing MUST use one shared composition engine and one Section/Variant registry.

User Color Editing

The ONLY user-editable surface colors remain:

PageBackground / زمینه صفحه

SectionSurface / بخش اصلی

SectionAlternate / بخش جایگزین

SectionAccent / بخش برجسته

No CSS editor. No raw hex per component. No per-section CSS.

Section Ordering

No mandatory Home structure.
User may start with Carousel, Banner, Category, Product section, or omit any section entirely.
Home/Landing = ordered list of valid Sections.

Variants

Each Section Type may have MANY curated Variants.
Variants are code-owned, previewable, responsive, bounded, and understandable.

Responsive / Mobile

Mobile behavior is SYSTEM-OWNED.
User does NOT configure breakpoints, mobile columns, px widths, or arbitrary mobile heights.
Each Variant has a canonical Responsive Contract.

Desktop may expose bounded presets, e.g. Hero height:

Compact

Medium

Large

ExtraLarge

Mobile maps automatically into safe capped behavior.

Templates

Industry templates are composition presets using the SAME registry.
Choosing a template creates a normal editable Draft.
No hidden template-specific rendering code.
