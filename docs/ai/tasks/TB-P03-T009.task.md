At minimum distinguish:

Stackable
Exclusive

Do not apply promotions in arbitrary database row order.

Pricing Boundary

Locked order of commercial evaluation:

Authored Base Price
→ Promotion/Discount
→ Tax Calculation
→ Order Snapshot

Promotion consumes Pricing result/snapshot as input.

Hard rule:

Promotion does not become authored Pricing truth

Tax Boundary

Tax must be calculated on the correct post-discount taxable base according to accepted tax policy.

Do not hard-code jurisdiction law.

For this foundation, ensure checkout passes the discounted tax-exclusive amount into Tax.

Do not let Promotion calculate tax.

Checkout Integration

Checkout must:

revalidate Pricing
evaluate Promotion
calculate Tax
persist immutable Order snapshots

If a promotion was present in Cart quote, checkout must re-evaluate it.

Expired/ineligible promotions must not silently remain applied.

Return an explicit outcome when commercial total changes and reconfirmation is required.

Order Snapshots

Persist immutable promotion/discount history on Order.

At minimum preserve:

PromotionId/reference
Promotion name/code snapshot where safe
DiscountType
DiscountAmount
Currency
PreDiscountTaxExclusive
PostDiscountTaxExclusive
AppliedAt

Historical order totals must not change when a Promotion later expires/changes.

Cart Boundary

Cart may store promotion quote/reference for UX.

Cart is not promotion source of truth.

Checkout re-evaluates.

Usage / Redemption Seam

Provide a durable future seam for:

per-user limit
per-order limit
global usage limit
coupon redemption count

If implementing current redemption accounting, it must be concurrency-safe.

A minimal evaluation-only seam is acceptable if usage limits are explicitly deferred.

Tenant / Edition Isolation

Marketplace promotion data lives in marketplace DB.

SingleStore promotion data lives in tenant DB.

No Host parsing inside Promotion.

Tenant A promotions cannot apply to Tenant B.

Authorization

No final promotion-admin permission matrix.

Use existing authorization guard seam.

No Authzed.Net types in Promotion Domain/Application.
