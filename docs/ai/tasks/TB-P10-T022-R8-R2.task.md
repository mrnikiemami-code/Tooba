Title:
Store Preview Asset Isolation Repair — Dedicated Preview-Fake Content/Media, Zero Template Asset Reuse

Architect Review

TB-P10-T022-R8-R1 is technically accepted, but user inspection exposed one remaining product-level defect:

In Store mode, PreviewFillPolicy correctly uses in-memory fake items, but those fake items reuse Fashion Template media/assets (FASHION_IMAGES or equivalent). This causes Sample-mode visuals to appear inside Store preview and makes the user believe Template data leaked into their Store data.

This is NOT acceptable.

The three data/media domains must be visually and technically isolated:

Sample Preview
-> persistent Template Catalog content/media only

Store Preview
-> operational Store content/media only
-> if insufficient, fill missing visual slots with dedicated Preview-Fake content/media

Published Storefront
-> operational Store content/media only
-> never Preview-Fake

Preview-Fake data/media must be independent from Template Catalog content/media, even when both are local files.

Do NOT expand to other industries.
Do NOT implement cloning.
Do NOT invent TB-P10-T023.
