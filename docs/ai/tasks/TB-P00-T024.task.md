# A. Classification System

Every reviewed capability MUST receive exactly one of:

```text
DEDICATED_TASK_REQUIRED
BOUNDARY_SUFFICIENT_FOR_P00
DEFER_POST_P00
NEEDS_USER_PRODUCT_DECISION
```

Definitions:

```text
DEDICATED_TASK_REQUIRED
= the capability creates important domain/data/security/transaction/UI boundaries
  that are not yet sufficiently designed; P00 Gate must wait.

BOUNDARY_SUFFICIENT_FOR_P00
= architectural seams/ownership are already sufficiently established by
  accepted documents; deeper design may occur later without risking P00 foundation.

DEFER_POST_P00
= capability is explicitly non-essential to the first architecture baseline
  and can safely be designed later without architectural leakage.

NEEDS_USER_PRODUCT_DECISION
= architecture cannot decide safely because an unresolved product/business
  choice materially changes the boundary or first-release scope.
```

Vague classifications are forbidden.
