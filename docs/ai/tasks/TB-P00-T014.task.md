# A. SEO as Architecture

Define:

```text
SEO Engine / Policy
Semantic SEO inputs
Public crawlable document
Lighthouse / CWV score
```

Hard rule:

```text
SEO is not a metadata afterthought
```

SEO influences routing, page ownership, content lifecycle, catalog identity, URL stability, localization, market handling, facet policy, composition, performance, rendering, internal linking, structured data, sitemap, robots, and redirects.

Lighthouse score alone is not SEO architecture.

```text
Content provides semantic SEO inputs
Catalog provides product facts
Pricing / Inventory provide commercial facts
Page Composition provides layout binding
SEO Engine / Policy owns technical SEO composition
```

Must not own as SoT: Catalog Product identity, Offer commercial terms, CMS body, Media binaries, Search index writes, Payment, Cart/Checkout/Order, Theme chrome as write model.

No module may treat SEO as optional title tags bolted on after UI.

---

# B. SEO Ownership Model

SEO policy owns:

```text
route-type policy
index / noindex
canonical
hreflang
metadata composition
structured-data composition
sitemap inclusion
robots.txt / robots meta
redirect coordination
SEO diagnostics
```

Owning modules supply inputs via contracts / projections / events.

SEO does not own Catalog write model, Content body, Price Book, Inventory ATS, or frontend component trees.

```text
Backend/module boundary != UI boundary
```

Admin/module screens may compose many SEO facts. That does not authorize cross-module table joins or a single CRUD form as the public storefront.

```text
Locale != Market != Currency
```

```text
RECOMMENDED_FOR_ADR
```

# E. hreflang

Alternate locale URLs for equivalent documents.

x-default policy:

```text
NEEDS_LATER_P00_DETAIL
```

# F. Canonical URLs

Every indexable page has exactly one canonical URL.

Parameters that do not change resource identity (sort, tracking, display currency) canonicalize away.

Canonical host is the public storefront host for the resolved tenant, not an internal alias, CDN origin, or preview host.

Unknown tenant / Host used as tenant SoT => fail closed (T003). Do not emit cross-tenant canonicals.

---

# G. Product Canonicalization

One canonical Product URL per public product document.

Duplicate paths (id-only, trailing slug variants) redirect to the canonical.

Offer URLs must not become competing product canonicals.

Catalog supplies identity / slug **inputs**. SEO owns canonical composition. No Catalog/SEO table joins.

Preserve product merge / redirect (T008). Details of merge URL history:

```text
NEEDS_LATER_P00_DETAIL
```

---

# H. Variant SEO

Default: canonical toward parent Product unless a variant is an explicit distinct crawl target with unique value.

Avoid indexing every combinable option as a thin page.

Exact variant-vs-product index rule:

```text
NEEDS_LATER_P00_DETAIL
```

---

# I. Seller Offer SEO

Marketplace customer SEO target is Product (structured data may include selected / competing Offers from projections).

Do not create a forest of indexable Offer URLs.

Seller storefront pages are a separate route type with selective index policy.

Seller SKU is not a public canonical identity (T008).

Single-Store must not invent a fake seller URL forest.

---

# J. Category / Taxonomy SEO

Indexable category pages require unique editorial and/or substantial catalog value where otherwise thin.

Multiple-category membership: one primary canonical category path.

Catalog commercial taxonomy != Content editorial taxonomy (T013 H). Mapping by opaque ids / contracts only.

---

# K. Brand SEO

Brand landing is indexable composition + Catalog brand facts + optional Content.

Not a seller commercial page. Not Offer SoT.

---

# L. Content SEO

Published Content items receive stable localized slugs as **inputs**.

Draft / in-review / unpublished must not enter sitemap or indexable canonical graphs.

Slug history → redirect (T013 AC). Ownership split:

```text
SEO coordinates technical redirect policy
Content / Catalog emit slug-change facts
```

Exact split remaining:

```text
NEEDS_LATER_P00_DETAIL
```

```text
Content != SEO Engine
```

Do not use `TitleFa` / `TitleEn` / `TitleAr` columns.

---

# M. Landing / Campaign SEO

Unique published landings may index.

Duplicate campaign clones: noindex and/or canonicalize to a durable URL.

Landings are Page Composition instances (T013), not hardcoded route products.

---

# N. Search Results SEO

Internal search result URLs default:

```text
noindex, follow
```

Do not sitemap. Query URLs are not product canonicals.

Do not implement Search in this task (later P00-15). Design indexation policy only.

---

# O. Faceted Navigation

Facets are a crawl-risk.

Policy: index only allowlisted facet combinations that have unique value; others noindex and/or canonical to the category (or other parent) URL.

Never allow infinite crawl of filter permutations.

Facet UX may be rich (filters, chips, drawers) while crawl policy stays strict.

```text
Backend/module boundary != UI boundary
```

Exact allowlist:

```text
NEEDS_LATER_P00_DETAIL
```

---

# P. Filter / Sort / Pagination Parameters

Sort, view, and tracking parameters: canonical to the clean resource URL.

Pagination: crawlable paginated URLs (or equivalent); do not spawn duplicate fully-indexable copies of page 1.

Do not lock `rel=prev/next` vs other pagination signals as the only mechanism; record candidates.

---

# Q. Programmatic SEO

High-volume generated pages are allowed only with unique value, canonical, hreflang, sitemap budget, and thin-content gates.

Not auto-index every attribute combination.

Programmatic SEO is not a second Catalog and not a substitute for Content.

---

# R. Thin / Duplicate Content Control

Quality gate before index: unique title/description/body and/or substantial catalog + editorial.

Duplicates canonicalize or noindex. Soft-404 (HTTP 200 empty) is forbidden for missing resources.

---

# S. Redirect Architecture

301 for permanent slug / identity changes; preserve history.

302 only for explicitly temporary cases.

Redirect policy coordinates; Content / Catalog / Composition emit change events. Outbox-ready (T004). No silent 200 duplicates.

Do not implement a redirect product now.

---

# T. Sitemap Architecture

SEO owns sitemap composition from a **published indexable** route feed.

Split by type if large. Lastmod from owning-module events, not live foreign-table scans.

Exclude: noindex, admin, cart, checkout, account, internal search, preview, unpublished.

Per public host / tenant. No cross-tenant URLs.

Do not implement sitemap XML now.

---

# U. robots.txt

SEO policy owns `robots.txt` per public storefront host.

Disallow admin / checkout / account / internal search as needed.

Do not block CSS / JS required to render the public document.

Staging / preview hosts are not production robots truth.

---

# V. Robots Meta / X-Robots-Tag

Page-level index / noindex / nofollow from route policy + publish state.

Preview / staging: noindex fail-closed.

Header vs meta composition:

```text
NEEDS_LATER_P00_DETAIL
```

# W. Structured Data

JSON-LD composed by the SEO layer from module **projections**.

Invalid / partial data is omitted rather than invented.

No SQL / ORM joins across Catalog, Pricing, Inventory, Content, Media tables to build JSON-LD.

Do not implement JSON-LD now.

---

# Z. Internal Linking

Category / product / content hubs.

Do not invent a full link-checker product now.

# AA. Pagination / Infinite Scroll

SEO-accessible paginated URLs (or equivalent crawlable pages) are required for indexable lists.

Infinite scroll must not be the only path to subsequent items.

```text
Backend/module boundary != UI boundary
```

Rich mobile infinite scroll may exist; crawlable pagination remains the SEO document strategy.

# AB. Rendering Strategy

Public indexable HTML must be crawlable (SSR or equivalent first-class HTML document).

Client-only empty shells are not the SEO document.

Admin / seller ops may be SPA.

Do not lock frontend framework here (later P00-21).

# AC. Core Web Vitals

CWV is SEO-relevant, not a vanity Lighthouse target.

Constraints: Media transformed variants (not originals only), bounded Page Composition, no unbounded nested widgets (T013 AJ).

Details with frontend / template adaptation (later P00-21).

Do not lock frontend stack or CDN vendor here.

# AD. UI/UX and SEO Compatibility

UI/UX is commercially critical (T000). Production-grade, mobile-intentional, accessible, multilingual.

SEO must not force developer-skeleton screens, ugly query-string forests as primary UX, or module CRUD as the storefront.


---

# AE. Mobile SEO / UX

Mobile-first crawl.

Same canonical content as desktop: responsive, not cloaked.

Do not maintain a separate mobile URL forest as the default model.

---

# AF. Accessibility and Semantic HTML

Semantic headings, `lang`, Media alt.

Accessibility is a production constraint, not a later bolt-on (T000 / T013 AI).

SEO markup must not contradict visible accessible names.

# AI. Market-Specific SEO

Market may change offer / price / availability, not language.

# AJ. Currency Parameters

Currency switch is not a new indexable document.

Canonicalize currency query / cookie display away from the product identity URL.

Do not emit per-currency canonicals as the default.

---

# AK. Tenant SEO

Each public Host has its own robots, sitemap, and canonical host.

No cross-tenant URL leakage in sitemaps, hreflang, or canonicals.

Do not parse Host as tenant SoT inside SEO. Consume resolved tenant context (T003).

Unknown tenant => fail closed. Do not index a default store.

Marketplace vs Single-Store share the SEO engine; edition policy differs, not a second SEO product.

---

# AL. Marketplace SEO

One marketplace public host: product-centric index; seller pages selective.

Single-Store: same engine; implicit seller; no fake seller URL forest.

Do not scatter `if (isMarketplace)` as the SEO model. Use composition / policy.

---

# AM. Preview / Staging

Preview / staging: noindex, not in production sitemap, fail-closed if accidentally public.

Not a production canonical. Preview tokens fail closed (T013 Z).

Do not implement preview tokens now.

---

# AN. Error Pages

Soft-404 (200 empty) forbidden for missing products / content.

Unpublished public request: not 200 indexable.

# AV. Decision Summary

Classify:

```text
RECOMMENDED_FOR_ADR
NEEDS_LATER_P00_DETAIL
DEFERRED
```

At minimum recommend for ADR:

1. SEO is an architecture concern, not afterthought metadata.
2. SEO policy owns technical composition; modules supply inputs via contracts / projections.
3. Locale-prefixed (or equivalent first-class) public routing; Locale != Market != Currency.
4. hreflang for locale equivalents only; Market is not a language alternate.
5. One product canonical; Offer URLs do not compete.
6. Internal search noindex by default; not in sitemap.
7. Facet crawl allowlist / canonicalize; no infinite permutations.
8. Redirect + slug / identity history coordinated with Content / Catalog events.
9. Sitemap of published indexable URLs only; per public tenant host.
10. Crawlable HTML for public indexable pages (SSR or equivalent).
11. Structured data from projections, not cross-module joins; omit rather than invent.
12. Currency / sort / tracking params are not new documents.
13. Tenant-isolated robots / sitemap / canonical host; Host is not SEO tenant SoT.
14. Production UX is not sacrificed for crawl hacks; Backend/module boundary != UI boundary.
15. Content != SEO Engine; Content supplies metadata / slug inputs.

Do not create the final ADR in this task.
