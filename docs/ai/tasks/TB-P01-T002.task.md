
No hard-coded collector URL.

## 6. Trace / Correlation

Use W3C trace context.

Preserve/emit:

```text
TraceId
SpanId
```

in structured technical logs where practical.

If an incoming request carries valid trace context, continue it.

Do not invent a separate competing correlation system unless needed.

If a separate correlation/request id is retained, document why and how it relates to TraceId.

---

## 7. Structured Technical Logging

Replace/minimally improve bootstrap logging so technical logs are structured and production-ready.

Requirements:

```text
no secrets
no Authorization header values
no cookies
no passwords
no OTP values
no connection strings
no raw payment data
```

Technical logs may include safe fields such as:

```text
request method
route/path template where safe
status code
duration
TraceId
environment
service
```

Avoid high-cardinality/noisy logging by default.

---

## 8. Standard Error Handling

Implement centralized backend exception/error handling.

Use standards-based:

```text
ProblemDetails
application/problem+json
```

for API errors where applicable.

At minimum distinguish conceptually:

```text
validation/client error
not found
conflict
unauthorized
forbidden
unexpected server error
```

Do NOT invent business exception taxonomy yet.

Provide reusable mapping seam for later modules.

---

## 9. Error Information Safety

Production errors must not expose:

```text
stack traces
file paths
connection strings
internal SQL
secrets
provider credentials
```

Development environment may expose controlled diagnostics if appropriate.

Unexpected exceptions must be logged with TraceId.

Customer-facing error payload should carry a safe correlation identifier/TraceId.

---

## 10. ProblemDetails Extension Contract

Establish a small stable extension convention, for example:

```text
traceId
errorCode
```

Do not overfill ProblemDetails.

`errorCode` may be absent for generic framework/unexpected errors.

Do not put localized customer copy into backend technical exception messages as architecture truth.
