Typed Filters

Mandatory filter types:

text
number
money
date
enum
boolean
entity
status

Each must have a typed value contract.

Text operators:

contains
equals
startsWith

Number/Money operators:

equals
greaterThan
greaterThanOrEqual
lessThan
lessThanOrEqual
between

Money preserves Currency context where required.

Date operators:

on
before
after
between

Canonical values remain ISO/canonical; Jalali is presentation/input only.

Boolean must support tri-state:

all
true
false

Entity filter must expose an async provider/search adapter without embedding feature API calls in the generic Grid.

Sorting

Support deterministic serializable sorting.

At minimum:

single-column
ascending/descending
server-side serialization

Multi-column sorting is preferred if it remains clean.

Column Operations

Implement:

reorder
resize
show/hide
restore defaults
sticky start/end capability

Persist relevant state in saved views.

Column resize must respect min/max widths and RTL.

Keyboard-accessible fallback for resize/reorder should exist where practical.

column widths
page size
optional density

Local storage may be used as a demo adapter only.

Hard rule:

saved-view model must be storage-agnostic

Provide future server persistence adapter interface.

Query State / URL

Provide adapter-friendly serialization of shareable state:

Permissions / i18n

Grid accepts permission/visibility decisions from feature layer.

No direct SpiceDB calls.

Performance

Avoid:

rendering thousands of rows at once
expensive full-table re-renders
client-side filtering of server-sized datasets

Virtualization may be deferred if not yet justified, but architecture must not block it.
