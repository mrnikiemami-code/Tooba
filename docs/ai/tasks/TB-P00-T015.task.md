# A. Search as Architecture

Define:

```text
Search Engine / Index
Search Document (projection)
Query / Ranking
Storefront search UX
```

Hard rule:

```text
Search Engine implementation must not leak into business domains
```

Search is a discovery engine over **projections**. It is not Catalog, not Pricing, not Inventory, not Content CMS, not SEO policy, and not first-party analytics.

```text
Catalog / Content / Offer / Pricing / Inventory emit facts
Search owns document assembly, index, and query contract
SEO owns crawl / indexability of public URLs
Frontend owns search UX composition
```

Must not own as SoT: Catalog Product identity, Offer commercial terms, Price Books, Inventory ATS, CMS body, Media binaries, Payment, Cart/Checkout/Order, Theme chrome as write model, SEO canonical/hreflang/sitemap.

No module may treat Search as optional `LIKE` on its own tables as the product search architecture.

Lighthouse / SEO crawl is not Search architecture. Internal search result URLs are not product canonicals (T014 N).

---

# C. Search Boundary

Inbound:

```text
projection / feed documents
query + context (tenant, locale, market, currency, authz / channel)
index commands (upsert / delete) from consumers of owning-module events
```

Outbound:

```text
ranked resource ids
denormalized display fields safe for result cards
facet counts
diagnostics (empty, degraded)
```

Search is not SoT for sellability, charge, stock commit, or canonical Product identity.

```text
Backend/module boundary != UI boundary
```

Admin may compose Search ops UX. That does not authorize cross-module table joins or treating Search CRUD as the public storefront.

---

# D. Search Document

Documents are **assembled projections**, not ORM entities and not write-model rows.

Typical conceptual fields (not a schema lock):

```text

searchable text
filter / facet keys
sort keys (projected price, recency)
flags (published, in-stock projection)
locale
market eligibility keys
tenant / store id
version / event offset
```

Do not store PAN, secrets, or raw PII as searchable text by default.

```text

```

Do not implement mappings now.

# E. Document Ownership

Owning modules emit facts via contracts / projections / events (T004 outbox-ready).

A Search assembly service (platform Search module) builds documents.

Catalog does not write ES mappings. Content does not own the product index. Pricing does not own query ranking code inside Price Books.

Search may own **derived** document fields. It must not become a second Catalog write model.

---

# F. Projection Assembly

Join-equivalent assembly happens **inside Search** from feeds, never SQL / ORM across Catalog, Offer, Pricing, Inventory, Content, Media, Seller tables.

Stale projected fields are allowed for browse.

Checkout / Payment revalidate price and stock (T009 / T010 / T011). Search must not be treated as quote SoT.

No dual-write from Admin forms into the engine as the indexing path.

---

# G. Indexing Flow

Default path:

```text
domain event → outbox → search consumer → upsert / delete document
```

Idempotent by document id + version / event identity.

Unknown / malformed events fail closed for that document (skip or quarantine), not silent corruption of another tenant's index.

Do not implement consumers, outbox, or workers now.

---

# H. Rebuild / Backfill

Full rebuild from source **feeds**, not live foreign-table scans from Search into owning-module schemas.

Versioned index alias / swap (or FTS table swap equivalent) so rebuild does not tear the live query contract.

No dual-write from Admin into the engine as rebuild.

# I. Index Versioning

Documents carry schema / mapping version.

Mapping changes require a reindex job, not in-place mutation of unrelated domains.

Do not lock alias naming now.

# J. Multilingual Search

Analyzer / text pipeline is per **Locale**.

Query uses request locale. Market is not a language. Currency is not a language.

```text
Locale != Market != Currency
```

Do not use `TitleFa` / `TitleEn` / `TitleAr` columns as the localization model (T013 / T014).

Untranslated locale variants must not be indexed as if they were complete translations.

Do not implement analyzers now.

# AV. Decision Summary

Classify:

```text
RECOMMENDED_FOR_ADR
NEEDS_LATER_P00_DETAIL
DEFERRED
```

At minimum recommend for ADR:

1. Search is projection-only; no write-model ownership of Catalog / Price / Inventory / Content.
2. Search Engine implementation must not leak into business domains; internal contract only.
3. Initial PostgreSQL FTS; Elasticsearch / OpenSearch later behind the same ports.
4. Event-driven upsert / delete plus feed-based rebuild; outbox-ready consumers.
5. Tenant-scoped documents and queries; fail closed if context missing.
6. Locale vs Market vs Currency remain independent on documents and queries.
7. Price and availability in the index are projections; checkout revalidates.
8. Public search result URLs default noindex; SEO owns facet crawl allowlists.
9. Draft / unpublished content excluded from public search.
10. Unified storefront query UX may sit on vertical indexes behind one API.
11. Authorization-aware public vs admin search; SpiceDB-compatible visibility.
12. Eventual consistency accepted for browse, never for charge or stock commit.
13. FTS storage lives in Search's own schema, not on domain write tables.
14. Production search UX is mandatory later and is not module CRUD; Backend/module boundary != UI boundary.
15. Marketplace vs Single-Store share one Search engine; edition policy differs.

Do not create the final ADR in this task.
